# Flashcards installeren

## Windows-computer

1. Download of clone de repository.
2. Dubbelklik op `install.bat`.
3. De installer kopieert de volledige app naar `%LOCALAPPDATA%\Studiekaarten`, maakt een snelkoppeling op het bureaublad en opent Flashcards.

## Telefoon

De telefoon installeert Flashcards als webapp via GitHub Pages (HTTPS); `install.bat` is alleen voor Windows-computers.

Eenmalig Pages inschakelen voor deze repository:

1. Open de repository op GitHub en ga naar **Settings → Pages**.
2. Kies bij **Build and deployment** als source **Deploy from a branch**.
3. Kies branch `main` en map `/(root)`, en sla op.
4. Wacht tot GitHub Pages de site publiceert. De URL is `https://s1156856.github.io/studiekaarten/`.

Installeren op de telefoon:

1. Open de Pages-URL in Safari op iPhone of Chrome op Android.
2. iPhone: tik op Delen, kies **Zet op beginscherm**, en bevestig.
3. Android: open het menu (⋮) en kies **App installeren** of **Toevoegen aan startscherm**.
4. Start Flashcards voortaan via het beginschermicoon. Na de eerste online opening werkt de app ook offline.
